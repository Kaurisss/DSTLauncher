# 05 — 世界设置与配置预览

**What to build:** 用户能在新主题下读取、编辑和保存各分片的世界设置，并查看对应的配置预览，确认所选房间及分片的最终配置。

**Blocked by:** 01 — 预设主题下跑通安装与开服

**Status:** ready-for-agent

**Implementation note (from 02):** 房间切换隔离已由 App 的房间级视图 key 提供；本票仍需复现并处理 WorldView 在同一房间内快速切换分片时的过期响应，避免旧分片草稿覆盖当前分片。

- [ ] 世界设置、预设选择、选项控件和配置预览采用 a6fJPbAx 主题，继续使用现有世界设置和配置接口。
- [ ] 所选房间与分片贯穿加载、修改、保存和重新读取；切换对象时不把未完成请求的结果显示到错误对象。
- [ ] 保留原有枚举、数字、布尔及未知选项值，既有自定义配置不会因换用新控件而被覆盖或丢弃。
- [ ] 保留运行中冻结、已生成世界限制、世界类型与预设不匹配提示，以及禁用覆盖配置时的说明。
- [ ] 保存失败保留草稿并显示原因，保存成功后预览内容与服务端返回一致，不在前端重新生成配置文件。
- [ ] 用隔离房间验证加载、编辑、保存、预览及冻结场景，并通过现有测试、静态检查及构建。
