# 06 — 模组搜索、下载与配置

**What to build:** 用户能在新主题下查找创意工坊模组、下载到共享目录、为当前房间启停与配置模组，检查和安装更新，并安全删除或重新下载。

**Blocked by:** 01 — 预设主题下跑通安装与开服

**Status:** ready-for-agent

- [ ] 模组搜索、详情、列表、配置和下载状态采用 a6fJPbAx 主题，保留现有创意工坊、模组及更新接口和共享目录模型。
- [ ] 按 ID 或链接查询、关键词搜索及 API Key 配置保持可用；密钥不出现在通知、控制台或测试产物中。
- [ ] 下载、更新、停止与失败重试的状态清楚可见，保留服务端任务互斥；重复操作不会创建冲突任务。
- [ ] 启用、禁用及配置保存作用于提交时确定的房间；保留模组 Lua 值归一、未知配置值和既有配置选项。
- [ ] 删除或重新下载前使用可访问确认框并保留共享文件影响警告；取消不删除文件，也不发送下载请求。
- [ ] 保留缺失模组、旧版本、运行中限制和文件占用提示；下载完成后刷新相关状态，错误时保留可恢复入口。
- [ ] 覆盖配置值类型、确认取消、切房间与任务失败的回归场景，通过现有测试、静态检查及构建；真实网络下载作为单独明确的验收操作。
