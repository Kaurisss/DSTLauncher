# 03 — 房间创建、编辑与管理员管理

**What to build:** 用户能在新主题界面中创建和编辑房间、管理任意数量的分片及管理员，并安全删除房间；所有修改经过现有接口保存，刷新后仍然正确。

**Blocked by:** 01 — 预设主题下跑通安装与开服

**Status:** ready-for-agent

- [ ] 房间列表、页内编辑面板、分片设置及管理员管理采用 a6fJPbAx 主题，保留页内编辑交互，不强制改成弹窗。
- [ ] 创建、编辑、保存及重新加载形成完整闭环；保留数字、布尔、空值、默认值和文本修整的原有语义，不把表单值统一转换成字符串。
- [ ] 保留令牌、在线或离线模式、端口、多分片及世界类型设置，保留主世界保护与运行中修改的既有约束。
- [ ] 管理员增加、移除和保存可用；操作执行期间切换房间不会把修改应用到新选择的房间。
- [ ] 房间、分片和管理员的删除或移除确认使用可访问确认框；取消不发送变更请求，确认期间正确保持操作目标并防止重复提交。
- [ ] 保存错误保留用户输入并清楚显示原因；房间删除后的选择回退与现有行为一致。
- [ ] 补充表单值类型、确认取消和切房间目标的回归检查，通过现有测试、静态检查及构建；数据操作使用隔离房间。
