# 04 — 存档上传与导入反馈

**What to build:** 用户能在新主题下选择存档整包，选择新建房间或覆盖目标房间，看到上传、解压及导入的完整过程，并在完成后找到导入结果；失败时保留可操作的错误反馈。

**Blocked by:** 01 — 预设主题下跑通安装与开服

**Status:** ready-for-agent

- [ ] 导入继续使用页内面板与现有上传接口，采用 a6fJPbAx 主题；保留整包解析与新旧配置兼容行为，不另写导入格式或后端解析器。
- [ ] 新建房间与覆盖已有房间两种模式都可完成，提交前清楚展示目标，提交期间切换房间不改变已选目标。
- [ ] 区分传输百分比与后续解压、导入阶段；上传达到 100% 后继续显示处理中，只有服务端确认成功后才显示完成。
- [ ] 覆盖前保留明确的破坏性警告与确认；取消不会上传或覆盖，重复点击不会创建多个任务。
- [ ] 保留文件与归档安全校验、错误回滚以及服务端警告；失败后显示原因并允许重新选择或重试，不展示虚假的成功结果。
- [ ] 成功后刷新房间和存档状态，用户能够直接找到新建或被覆盖的目标房间。
- [ ] 使用一次性测试归档覆盖成功、覆盖取消、导入失败与上传后处理场景，通过现有测试、静态检查及构建；不使用真实存档做破坏性验收。
