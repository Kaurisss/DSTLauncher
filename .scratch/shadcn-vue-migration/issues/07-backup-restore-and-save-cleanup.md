# 07 — 备份、恢复与存档清理

**What to build:** 用户能在新主题下创建、下载和恢复备份，删除不再需要的备份，并识别及安全清理孤儿存档；每个破坏性操作都能明确确认或取消。

**Blocked by:** 01 — 预设主题下跑通安装与开服

**Status:** ready-for-agent

- [ ] 备份列表、恢复入口及存档盘点采用 a6fJPbAx 主题，沿用现有备份、恢复和存档管理接口。
- [ ] 手动备份、下载、恢复和删除形成完整闭环；任务完成后刷新列表，失败时显示原因并保留可恢复操作。
- [ ] 恢复、删除备份和永久删除存档使用可访问确认框，保留原有破坏性中文警告；取消不发送变更请求。
- [ ] 确认期间切换房间或刷新列表不改变原操作目标，重复点击不会重复恢复或删除。
- [ ] 保留正在运行的房间、仍被房间引用的存档及孤儿存档清理限制，不为统一界面弱化后端保护。
- [ ] 浏览器下载仍使用现有文件下载方式，不将备份整包改为普通 JSON 请求。
- [ ] 仅用隔离存档和备份验证恢复、删除、取消与限制场景，通过现有测试、静态检查及构建。
