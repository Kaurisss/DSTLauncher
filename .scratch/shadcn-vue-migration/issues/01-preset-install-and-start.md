**What to build:** 在用户指定的主题预设 a6fJPbAx 下，用户能够安装 DST 专用服务器、查看各阶段百分比，并在安装成功后启动原先选择的单个分片。新旧界面在迁移期间共存，未迁移页面继续正常使用。

**Blocked by:** None — can start immediately

**Status:** done

**核验记录：**已核对用户提供的 [shadcn-vue 官方 CLI 文档](https://www.shadcn-vue.com/docs/cli)。Vue CLI 支持带预设的初始化，以及向现有项目应用预设。本票采用 shadcn-vue CLI 的原生预设流程，保留用户指定的 a6fJPbAx；此前超时的是另一套 shadcn CLI 调用。

- [x] 使用 shadcn-vue 官方 CLI 为现有 Vue 项目接入 a6fJPbAx，记录实际预设配置与 CLI 版本，并落实其配色、字体、圆角及组件风格；预设解析失败时保留原界面并报告具体错误，不自行换成默认主题或引入 React 组件。
- [x] 继续使用 Vue 3 和 JavaScript；不重写 Pinia、HTTP API、安装状态机、后端或数据格式，保留已有未提交的自动安装与阶段百分比改动。
- [x] 先扩展主题与兼容组件，再迁移本票场景；保留旧组件契约，处理主题变量和旧全局样式冲突，未迁移页面仍可操作。
