## 本票修复的实际问题

1. 切房立即清空旧分片状态；请求序号阻止旧房间或较旧响应覆盖当前状态。慢请求重叠时允许先展示有效响应，不因连续轮询而一直等待。
2. 房间业务页按页面与房间 ID 重建实例，隔离旧房间异步响应和未保存草稿；全局房间管理、存档目录页不因顶部选择变化而重建。
3. 浏览器实测原 Transition 快速导航留下 3 个视图实例，移除页面过渡后 28 次连续导航均保持单实例。
4. 日志滚动监听批量落账产生的新数组，达到 4000 行后仍可自动跟随；命令等待期间换房，不把旧房间命令回显写入新房间。
5. 模组页卸载后不再创建轮询，App 初始请求完成前卸载也不创建后续定时器。
6. 禁用展开状态和移动端的隐藏 Tooltip，避免其吞掉导航 Sheet 的第一次 Escape。移动导航关闭后焦点恢复到触发按钮。
7. 修正生成组件的 Hugeicons 数据导入与中文可访问标签，修正 768px 断点，保持本地字体并移除 CLI 再次插入的远程字体导入。

## 工具链处理

CLI 的 JS 转换使用注册表相对文件名解析同目录类型，而源码尚未落盘。通过 CLI view 获取官方源码，在系统临时目录提供完整类型解析目录，并仅为 CLI 进程把去类型函数的文件名改为绝对路径；仍由官方 CLI 生成最终 JS。未修改磁盘上的 CLI 包、全局 Node 或应用运行时，未切换预设。后续添加组件仍应检查类型路径转换、图标导入和远程字体注入。
