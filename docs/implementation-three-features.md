# 配置方案、故障诊断与通知

目标：实现房间配置方案复用、基于日志证据的启动/更新诊断、按房间订阅事件的 Webhook 通知，复用既有鉴权和维护互斥。

验收范围：

- 房间页保存、导入、导出、删除命名方案；从当前房间复制或从方案创建新房间。保留各分片世界及模组配置，重新分配端口和集群密钥，不携带存档、令牌和房间密码。
- 概览提供诊断面板，展示缺失令牌、分片日志和共享模组下载中的已识别错误、原始证据、建议及明确关联的工坊 ID/本地名称。
- 设置页配置通知地址、签名密钥、事件和房间，提供测试发送与最近投递结果；连续崩溃达到上限和自动维护失败能够触发通知，发送不阻塞服务器操作。
- 覆盖方案隔离及输入校验、诊断归因、Webhook 签名/筛选/失败反馈、页面交互；构建网页及桌面版。

现有 UI 间距、工具栏整合及滚动阴影属于本轮之前的改动，保留。

进展：三项功能已完成，网页与 Windows 桌面版已重新编译，Linux 构建通过。

验证结果：

- `go test ./...` 与桌面标签测试通过；通知、配置方案、进程事件及 Web API 的 race 检查通过。
- 新增 4 项浏览器用例通过，覆盖方案保存/导入/复制/应用、分片名称及诊断日志文本显示、通知保存及投递失败结果、375px 布局。
- 配置方案 API 测试覆盖四分片、停用洞穴、海难/火山完整世界定义、独立模组参数、端口/密钥隔离、令牌及密码剔除、不复制存档、导入文件与 Lua 校验、鉴权及维护互斥。
- 使用临时数据目录和临时服务器安装占位文件启动桌面版，实际调用方案保存与应用、诊断和通知 API，关闭窗口后退出码为 0。未启动游戏进程，未使用现有存档或修改真实服务器安装。
- 扩展浏览器回归运行 36 项，28 项通过，8 项失败。在临时副本中将本轮修改的房间页、概览页、设置页和 API 恢复为此前实现后，8 项仍以相同原因失败：旧玩家日志控件及行操作选择器、自动刷新次数断言、公告弹窗打开时点击背景房间选择器、房间表单顶部 1px 边框断言。这些旧用例和既有行为保留原样，本轮未扩大修复范围。

使用入口及协议见 [配置方案、故障诊断与事件通知](operations-features.md)。
