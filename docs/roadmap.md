# 面板优化与功能演进备份（Roadmap）

本文档记录对比主流开源饥荒联机版（DST）管理面板（如 `dst-management-platform`、`dst-admin-go`）梳理出的功能缺口与后续优化清单。

---

## 一、优先推荐落地项（Top 3）

### 1. 安全鉴权与宿主机资源预警
- **面板密码 / Token 登录**：当前 `/api/*` 无认证，仅能绑定 `127.0.0.1` 或依赖前置反向代理。支持在 `panel.json` 或环境变量配置访问密码（Cookie / Bearer Token 鉴权），便于云服务器直接部署。
- **宿主机总内存与磁盘剩余空间展示**：概览页除展示「运行中分片进程的 CPU / 内存」外，增加宿主机 **已用/总内存** 与 **存档盘剩余空间**，在开启多层分片（如四穿）内存不足时提前预警 OOM。

### 2. 在线玩家管理、黑白名单与快捷指令
- **在线玩家列表与快捷操作**：解析分片日志或通过控制台指令查询当前在线玩家（昵称、Klei ID、角色、存活天数），支持一键 **踢出、封禁、复活、传送、设为管理员**。
- **黑白名单可视化管理**：在房间页除 `adminlist.txt`（管理员名单）外，补齐 **`blocklist.txt`（黑名单/封禁列表）** 与 **`whitelist.txt`（白名单/预留位）** 的增删管理。
- **常用指令与全服公告（`c_announce`）快捷栏**：在概览/控制台提供全服公告输入框及常用操作按钮（立即保存 `c_save()`、跳过一天 `c_skip(1)`、重置世界 `c_regenerateworld()` 二次确认）。
- **玩家聊天日志视图**：单独提取并展示 `server_chat_log.txt` 中的游戏内聊天与进出服记录。

### 3. 定时任务与自动化运维
- **定时自动备份**：支持按固定间隔（如每 N 小时或每天指定时间）自动执行整房间存档备份，并按保留份数自动轮转清理。
- **定时重启与更新检测联动**：
  - 支持配置每日定时重启（重启前自动发送 `c_announce` 倒计时通知在线玩家并执行 `c_save`）。
  - 定期检测饥荒服务端本体或已启用创意工坊模组是否有更新，支持自动（或在服务器无玩家在线时）重启拉取更新。

---

## 二、其它体验增强项

### 4. 世界状态感知
- **世界天数与季节显示**：从存档 `session` 快照的 `.meta` 文件或分片日志中读取当前 **世界天数、当前季节（春/夏/秋/冬/温和/飓风/旱季/绿季）及本季剩余天数**，在概览页直观展示。

### 5. 动态 `modinfo.lua` 完整沙箱解析
- **轻量 Lua 沙箱执行 `modinfo.lua`**：目前采用纯 Go 静态语法/正则提取 `configuration_options`，已覆盖绝大部分字面量、双语表达式与 `STRINGS` 表；对于极少数使用自定义 Lua 函数（如 `AddConfig(...)`、循环动态拼表）构造配置项的模组（如 `Epic Healthbar`、`Upgradeable Chest`），可引入纯 Go 轻量级无副作用 Lua 沙箱（注入 `locale = "zh"`），实现 100% 模组配置项及中文翻译还原。
