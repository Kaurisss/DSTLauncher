# 面板优化与功能演进备份（Roadmap）

本文档记录对比主流开源饥荒联机版（DST）管理面板（如 `dst-management-platform`、`dst-admin-go`）梳理出的功能缺口与后续优化清单。

---

## 一、优先推荐落地项（Top 3）

### 1. 安全鉴权与宿主机资源预警（已完成）
- [x] **面板密码登录**：支持设置页管理密码、`-password` 参数和 `DST_PANEL_PASSWORD` 环境变量；业务 API 使用 HttpOnly Cookie 会话鉴权。
- [x] **宿主机内存与存档盘空间**：概览页每 5 秒刷新宿主机内存使用率、已用/总内存，以及存档目录所在磁盘的可用/总容量；没有房间时仍可查看。Windows 使用原生 API，Linux 使用 `/proc/meminfo` 与 `statfs`，无新增依赖。
- [x] **低资源提醒**：内存使用率达到 90%，或存档盘可用空间低于 10% / 5 GB 时展示提醒；采样失败单独显示错误，不显示虚假零值。只提示，不自动停止分片或清理存档。

> Linux 宿主机内存保留 `/proc/meminfo` 口径，另显示可读的 cgroup v1/v2 容器内存配额及父级约束，配额剩余不超过 10% 时提醒。

### 2. 在线玩家管理、黑白名单与快捷指令
- [x] **在线玩家列表与快捷操作**：概览页实时查询运行分片的玩家（昵称、ID、角色、存活天数、幽灵/管理员状态），每 15 秒刷新；支持踢出、封禁、复活、同分片玩家间传送，以及写入管理员名单（重启生效）。操作等待游戏回执，分片查询失败单独展示。
- [x] **黑白名单可视化管理**：房间编辑页支持 `blocklist.txt` 与 `whitelist.txt` 的增删、搜索及重启生效提示；白名单联动预留位，过滤无效/重复条目并限制为不超过最大人数。名单操作固定绑定编辑房间。
- [x] **常用指令与全服公告快捷栏**：概览提供等待所有运行分片落盘回调的立即保存、原生 `c_announce` 公告和需确认的主世界 `c_skip(1)`。操作等待游戏回执；快进与回档共用一分钟冷却。永久重置世界仍未加入快捷按钮。
- [x] **玩家聊天日志视图**：独立读取各分片 `server_chat_log.txt` 的近期聊天、私聊、进出和公告；支持类型与内容筛选、轮询和跨房间竞态保护。仅读取最近 1 MiB，不新增历史数据库。

### 3. 定时任务与自动化运维（已完成）
- [x] **定时自动备份**：设置 → 自动维护，按 1–720 小时间隔备份所有有存档的房间，每个房间保留 1–100 份自动备份。自动备份名称含 `_auto_`，在备份页统一查看、下载和恢复；只清理旧自动备份，手动备份仍独立保留最近 10 份。压缩包写入并关闭成功后才发布和轮转。
- [x] **每日重启**：按界面标注的宿主机时区执行。提前 60 秒、30 秒发送 `c_announce`；通过游戏 `ShardGameIndex:SaveCurrent` 的完成回调确认存档后停服，再恢复此前运行的分片，不启动原本停止的世界。
- [x] **更新检测联动**：每 15–1440 分钟检查服务端版本及所有房间已启用的工坊模组。支持仅检测、自动更新、所有房间无玩家连接时更新；“无人”包含选人界面连接，并在倒计时和保存后复查。更新前停止所有分片，成功后恢复原运行集合；更新失败保持停止并显示原因。
- [x] **持久化与互斥**：计划和最近执行结果保存在存档根目录 `automation.json`，默认全部关闭。任务串行执行，维护期间拦截冲突写操作并暂停崩溃自动重启；退出面板取消倒计时，不再启动分片。

> 计划作用于全部房间，仅在面板运行时执行；过期计划恢复后至多补跑一次，不逐次重放积压任务。保存计划不会立即执行任务或清理备份。Steam 外部安装仅检测服务端版本，由用户自行更新；自动更新只操作面板管理的安装。网络检测失败不会停服，详细结果见设置页。无人模式是停服前检查连接，不锁定新的游戏连接。

> 接口依据：[Valve 版本检测](https://partner.steamgames.com/doc/webapi/ISteamApps#UpToDateCheck)、[游戏存档回调实现](https://github.com/taichunmin/dont-starve-together-game-scripts/blob/master/shardindex.lua)。

## 二、其它体验增强项

### 4. 世界状态感知（已完成）
- [x] **世界天数与季节显示**：概览 → 世界状态，每 15 秒读取各启用分片最近的 `save/session/*/*.meta` 世界快照，显示世界天数（cycles + 1）、季节及本季剩余天数，支持春/夏/秋/冬及温和/飓风/旱季/绿季等名称。
- [x] **明确数据时间与失败状态**：标明存档时间；天数和季节是最近保存的数据，不是实时模拟状态。剩余 0 天正常展示，永久季节不显示虚假的剩余天数；无快照、字段缺失和读取失败分别展示。只解析静态 Lua 数据，不执行存档代码，也不读取玩家目录下的快照。

> 支持明文及 `KLEI     1 ` 头的元数据；压缩或动态 Lua 元数据会显示读取失败。字段依据：[游戏读取世界元数据的实现](https://github.com/taichunmin/dont-starve-together-game-scripts/blob/master/shardsaveindex.lua)。

### 5. 动态 `modinfo.lua` 完整沙箱解析
- **轻量 Lua 沙箱执行 `modinfo.lua`**：目前采用纯 Go 静态语法/正则提取 `configuration_options`，已覆盖绝大部分字面量、双语表达式与 `STRINGS` 表；对于极少数使用自定义 Lua 函数（如 `AddConfig(...)`、循环动态拼表）构造配置项的模组（如 `Epic Healthbar`、`Upgradeable Chest`），可引入纯 Go 轻量级无副作用 Lua 沙箱（注入 `locale = "zh"`），实现 100% 模组配置项及中文翻译还原。

功能来源、使用方法与后续候选项见 [dst-admin-go 功能对照](dst-admin-go-comparison.md)。
