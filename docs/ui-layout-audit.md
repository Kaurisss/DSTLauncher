# 前端页面布局与功能入口审查报告

本文档基于前端源码（`web/src/`），系统梳理 DSTWin 管理面板在**信息架构、功能入口归属、交互可发现性以及页面布局**方面存在的不合理之处，并跟踪三阶段重构落地情况。

## 整改进度总览

| 阶段 | 核心目标 | 状态 |
|---|---|---|
| 阶段 1 | 按钮可读性与高危入口分层（文字按钮规范、图标去重、概览快捷运维分层） | ✅ 已完成 |
| 阶段 2 | 重构导航分组与统一作用域（房间/全局双分组、顶栏作用域收敛、玩家管理整合、完整迁移归位、配置预览下沉、显式登出） | ✅ 已完成 |
| 阶段 3 | 归位错位入口与优化页面布局（概览安装/缺令牌横幅与内存主显、地图预览、世界预设外露、分片常驻、玩家日志精简与自动刷新归位、设置页 4 组合并、跨页跳转） | ✅ 已完成 |

## 一、导航与页面结构（重构前 → 重构后）

原侧边栏采用 9 项平铺导航，未区分「当前房间」与「全局管理」作用域；重构后收敛为 **2 组 8 项**，「配置预览」下沉为房间编辑与故障诊断弹窗内的次级入口：

| 分组 | 导航项 | 视图文件 | 实际作用域 | 主要承载内容 |
|---|---|---|---|---|
| 当前房间 | 概览 | `web/src/views/OverviewView.vue` | 当前房间 + 宿主机 | 安装/缺令牌引导条、资源指标卡（突出内存占用）、分片启停、快捷运维（含地图预览）、在线玩家、实时日志与控制台 |
| 当前房间 | 世界配置 | `web/src/views/WorldView.vue` | 当前房间（按分片） | 世界规则与世界生成可视化配置、可见预设与 `override_enabled` 配置栏 |
| 当前房间 | 模组 | `web/src/views/ModsView.vue` | 当前房间（按分片）+ 共享下载 | 模组启用/禁用、配置、更新检查、工坊添加、共享下载队列 |
| 当前房间 | 玩家管理 | `web/src/views/PlayerLogsView.vue` | 当前房间 | 双 Tab：玩家日志（7 列紧凑表格 + 顶部自动刷新开关）+ 管理员与准入名单 |
| 当前房间 | 备份与回档 | `web/src/views/BackupsView.vue` | 当前房间 | 单房间 ZIP 备份与恢复检查、游戏快照回档、直达异地备份设置入口 |
| 全局管理 | 房间管理 | `web/src/views/RoomsView.vue` | 全局 | 房间卡片列表、新建/编辑房间（含配置预览入口）、上传存档、配置方案、**全局完整迁移** |
| 全局管理 | 磁盘存档 | `web/src/views/SavesView.vue` | 全局磁盘 | 全磁盘 `Cluster_*` 盘点、孤儿存档删除、存档地图预览 |
| 全局管理 | 系统设置 | `web/src/views/SettingsView.vue` | 全局 | 4 个均衡分组：自动维护与异地备份、事件通知、服务器与创意工坊、安全/外观与关于 |

## 二、全局级核心问题

### 1. 全站过度使用「纯图标按钮（`IconAction`）」，可发现性差且图标撞车 — ✅ 已处理
- **原状**：`IconAction.vue` 固定渲染为 `size="icon-sm"` 纯图标按钮，概览页连续摆放 7 个纯图标按钮，弹窗按钮风格不统一，且 `refresh`、`clock`、`folder`、`activity`、`pin` 等图标在多处撞车。
- **处理结果**：
  - `IconAction.vue` 扩展 `showLabel`（支持响应式断点）与 `text` 属性，为页面/卡片主操作、弹窗确认/取消及低频概念入口补齐中文文字标签；
  - `Icon.vue` 新增语义化图标（`diagnostics`、`megaphone`、`rollback`、`map`、`migrate`、`templates`、`cloudCheck`、`plug`），消除同页/跨页图标冲突；
  - 概览页拆分为顶部「故障诊断 + 全部启动/停止」与底部独立「快捷运维」栏。

### 2. 侧边栏平铺无分组，「房间级」与「全局级」作用域混杂 — ✅ 已处理
- **原状**：9 项平铺导航，全局管理页仍常驻房间下拉选择器，下拉项无运行状态点。
- **处理结果**：
  - `ui.js` 与 `AppSidebar.vue` 拆分为「当前房间（5 项）」与「全局管理（3 项）」两组，收起态通过分隔线区分且隐藏标签文字；
  - `TopBar.vue` 在全局管理页隐藏房间切换器并展示「全局」标识；房间作用域页的房间选择器触发框与下拉项均增加运行状态指示点。

## 三、功能入口归属不合理与隐藏过深

### 1. 服务端首次安装进度与更新入口脱离「概览」主流程 — ✅ 已处理
- **处理结果**：`OverviewView.vue` 顶部新增实时安装进度卡（展示阶段、进度条、百分比与「取消安装」按钮），暂停/失败时展示可一键「继续安装 / 重试安装」或直达「服务器设置」的横幅；后端 `steamcmd` 同步支持随时取消并保留已下载分块用于续传。

### 2. 「存档地图预览」挂在「存档」页，作用域错位且难发现 — ✅ 已处理
- **处理结果**：在 `OverviewView.vue` 快捷运维栏补充 `<SavedMapDialog />`（地图预览）入口，同时保留磁盘存档页入口兼容既有习惯。

### 3. 「完整迁移」藏在单房间「备份」页中 — ✅ 已处理
- **处理结果**：将 `<MigrationDialog />` 从单房间 `BackupsView.vue` 迁移至全局 `RoomsView.vue` 工具栏，与「配置方案」「新建房间」「上传存档」聚合。

### 4. 「备份」「存档」「上传存档」「回档」概念重叠、入口分散 — ✅ 已处理
- **处理结果**：导航明确区分为房间级「备份与回档」与全局级「磁盘存档」，同时用不同图标和文字标签区分「游戏快照回档（`rollback`）」与「ZIP 备份回滚（`undo`）」。

### 5. 「玩家管理」能力分散三处，且房间编辑页混用两套提交模型 — ✅ 已处理
- **处理结果**：
  - `PlayerLogsView.vue` 升级为「玩家管理」双 Tab 页面（「玩家日志」+「管理员与准入名单」），封禁后可直接切 Tab 查看或解封；
  - `RoomsView.vue` 房间编辑页底部保留针对所编辑房间的名单维护能力，但新增明确分隔标题与提示说明「以下名单即时生效，与上方表单保存按钮相互独立」。

### 6. 「世界配置」的核心可写项藏在 `info` 信息气泡里 — ✅ 已处理
- **处理结果**：`WorldView.vue` 在普通 `worldgenoverride.lua` 模式下将「世界生成预设」「世界规则预设」「启用本文件（`override_enabled`）」移出 `info` 气泡为直接可见的配置栏；`info` 气泡专注于只读文件路径与生效说明。

### 7. 「配置预览」占独立一级菜单性价比偏低 — ✅ 已处理
- **处理结果**：移除独立主导航页 `ConfigView.vue`，封装可复用的 `ConfigPreviewDialog.vue` 并挂载到房间编辑工具栏与概览页「故障诊断」弹窗中。

### 8. 「设置」页二级导航过碎，且把高频/全局操作埋得过深 — ✅ 已处理
- **处理结果**：
  - `SettingsView.vue` 从 5 组 9 项合并为 4 个均衡分组（自动维护与异地备份、事件通知、服务器与创意工坊、安全/外观与关于）；
  - 「自动刷新玩家日志」开关迁回「玩家管理 → 玩家日志」顶部栏；
  - 启用密码保护时，在 `TopBar.vue` 右侧直接提供显式「退出登录」按钮；
  - `BackupsView.vue` 工具栏新增「异地备份设置」快捷跳转按钮，直达系统设置对应分组。

## 四、页面布局与交互一致性问题

### 1. 概览页（`OverviewView.vue`） — ✅ 已处理
- 「进程资源占用」改为以**内存占用**作为主数值，副标题展示 CPU 占比，更贴合 DST 易受内存限制的运维重点；
- `.overview-workspace` 调整为 `1.45fr : 1fr` 比例，给分片管理与快捷运维更充裕空间；
- 顶部补齐缺令牌（`room.needToken`）提醒条（一键跳转对应房间编辑）与安装进度/暂停/失败横幅；快捷运维补齐「地图预览」。

### 2. 分片切换交互不统一，且窄屏隐藏主维度 — ✅ 已处理
- 将 `ModsView.vue` 与 `PlayerLogsView.vue` 中的分片 `<Select>` 移出 `UiToolbarFilters` 折叠弹窗，在桌面与窄屏（320px+）下始终保持直接可见且工具栏维持单行不溢出。

### 3. 玩家日志表格过宽导致常规桌面端强制横滚 — ✅ 已处理
- `PlayerLogsView.vue` 表格由 10 列（`min-w-[1240px]`）精简合并为 7 列（`min-w-[820px]`）：合并「角色头像 + 玩家名 + Klei ID」为「玩家」列，合并「Steam ID + IP」为「网络标识」列，在常规 1280px / 1440px 桌面端无需横向滚动即可看到「内容」与「封禁」操作列。

### 4. 表格分页样式不统一 — ⏸ 延后（低优先级）
- `PlayerLogsView.vue`（吸底分页 + 每页条数）与 `SavesView.vue` / `BackupTable.vue`（轻量分页）数据量级差异较大，当前体验可接受，后续按需统一。

### 5. 跨页引导缺少快捷跳转 & 部分文案过期 — ✅ 已处理
- 为概览、世界配置、模组、玩家管理、备份与回档中的无房间空态和运行冻结提示补齐可点击的「前往新建房间」「前往概览」「前往配置令牌」「异地备份设置」跳转按钮；
- 修正过期文案：`WorldView.vue`（「总览」→「概览」）、`SaveUploadPanel.vue`（「更新模组」→「下载缺失」）。
