# 完整迁移包与地图预览

目标：为全部房间提供可校验、可预览、创建新房间的完整迁移流程；从最近保存点读取地表/洞穴地图，不执行 Lua。

验收范围：

- 迁移包含房间定义、所有已定义分片（含停用分片）的存档和配置、玩家名单、维护计划及配置方案。排除游戏程序、模组实体和面板访问凭据。
- 导出前停止全部房间。迁移包有版本、文件清单及 SHA-256；上传后校验并展示房间/分片清单，确认后创建新房间，重新分配 ID、端口、集群密钥。
- 维护计划由用户选择是否应用；不覆盖现有房间或自动启动导入房间。
- 地图预览标明保存点时间，可选房间和分片，支持缩放；格式事实与来源记录在 `dst-map-format.md`。
- 验证 ZIP 越界/重复项/大小/摘要、失败清理与已有存档隔离、多分片恢复、地图格式和页面交互；生成网页和桌面版。

进展：完整迁移与地形地图预览已实现，入口分别在「备份 → 完整迁移」和「存档 → 地图预览」。

实现与验证：

- 导出和应用在后台执行，通过维护互斥排除其他更改及定时维护，并暂停崩溃自动重启。上传先进入私有暂存目录；全部 ZIP 载荷通过 CRC、大小及 SHA-256 校验后才可应用。
- 通过批量房间事务分配 ID/端口/密钥，恢复各分片存档、配置、名单和方案，明确勾选时应用维护计划。覆盖准备失败、持久化失败、取消上传和退出清理。
- 归档测试覆盖越界路径、Windows 保留名、重复/大小写冲突项、符号链接、清单缺失、摘要篡改和解压上限；既有房间及存档隔离测试通过。
- 地图支持直接静态返回表及游戏的 `savedata` / `tablefunctions` 包装，仅词法扫描与静态表提取，不执行 Lua。兼容明文及常用 KLEI 压缩封装，排除玩家子目录，显示保存时间、区域图和地标。
- 只读验证项目现有森林（400×400）、洞穴（425×425）、海难（540×540）快照。逐格数据验证为完整 9 字节 VRSN 头 + LE16，三个世界地块 ID 均 100% 命中当前存档地形表。已替换初版区域多边形，直接渲染真实地形及海岸。
- Go 全部测试及桌面标签测试通过；迁移、房间、世界设置和 Web API 的 race 检查通过。
- 新增 4 项浏览器测试通过；连同已有备份、存档、配置方案等相关回归，共 16 项通过。覆盖自定义 Select、上传预览、计划显式勾选、确认取消、地图缩放/分片切换、错误恢复及 375px 布局。
- 隔离数据目录与临时服务器安装下，桌面程序完成真实 HTTP 导出/下载/上传校验/导入往返，导入前后均可读取构造世界地图；关闭窗口退出码为 0，临时任务已清理。
- 最终程序另外通过了 `savedata` 包装、NUL 终止符及 0–255 颜色的实际 HTTP 读取验证；网页、Windows 两个可执行文件及 Linux 构建已更新。

用户说明及接口见 [完整迁移与存档地图预览](../migration-map.md)。

地图改进：移植 MIT DMP Web 的地形配色、名称和缓存位图绘制，许可随网页及可执行文件发布。新增地标分类图标/标签避让、搜索定位、滚轮缩放/拖动/方向键、按真实引用的虫洞配对。来源及未采用的解码缺陷见 [源码复用调查](../dst-map-reuse-research.md)。

地形版最终验证：Go 全部测试与桌面标签测试通过，世界设置/Web API race 检查通过；16 项相关页面回归通过（含颜色像素断言、高 ID 地形、搜索定位、虫洞连线、拖动缩放与键盘复位）。真实森林/洞穴/海难地块解码共 632225 项均映射成功。最终桌面版在隔离目录实际验证地块 API、ID 10504、地标元数据、内嵌 MIT 许可及退出码 0；Windows 网页版/桌面版与 Linux 程序已重建。
