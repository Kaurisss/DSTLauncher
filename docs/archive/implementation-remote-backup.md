# 异地备份与恢复检查

目标：手动/自动备份成功后后台同步到指定目录（含 NAS）或 WebDAV；恢复前校验备份并预览世界信息和地图。

验收：

- 设置页配置单个目标、保留份数、WebDAV 账号密码，密码不回传；提供连接写入测试与最近同步状态。
- 备份完成进入后台队列，失败保留本地备份并接入 Webhook，可手动重试已有备份。远端仅清理本面板专属目录的备份。
- 逐项读取 ZIP 校验 CRC、路径/重复项/链接/大小限制，检查配置与分片世界保存点，汇总玩家存档和保存点天数/季节；复用现有地形预览。
- 恢复先验证/完整解压到新目录，通过后替换，失败时保留原房间；恢复绑定预览摘要，运行中房间禁止恢复。
- 测试目录/WebDAV 写入及轮转、失败与关闭取消、损坏包拒绝/恢复失败隔离、页面交互；重建网页和桌面版。

进展：两项功能已完成。设置页增加「异地备份」，备份页回滚先进入「备份恢复检查」。

完成验证：

- 目录目标及 WebDAV 模拟服务覆盖写入、临时文件改名、认证、目录清单、轮转、旧备份重试保留、失败回调及关闭取消；密码保留/清除与回传脱敏校验通过。
- ZIP 检查覆盖重复项、大小写冲突、路径越界、Windows 保留名、符号链接、CRC 损坏和解压上限。恢复失败保留原存档的用例先复现旧实现缺陷，再通过新实现。
- API 测试覆盖手动/自动备份后台入队、设置及鉴权、分片/玩家/天数报告、暂存地图、摘要绑定恢复和恢复前目录保留。
- Go 全部测试、桌面标签测试、backup/backupremote/web race 检查通过。
- 新增 4 项页面测试，加上备份、自动维护、地图迁移、配置方案、存档等相关回归共 23 项通过；覆盖自定义 Select、密码不回填、连接失败、检查确认取消、损坏包/运行房间禁止恢复、同步重试与 375px 布局。截图已检查。
- 最终桌面程序使用独立临时数据及临时服务器安装启动，实际 HTTP 验证本地备份→异地目录副本摘要匹配→两个分片/第 22 天检查→备份地图→摘要绑定恢复；恢复前世界保留，退出码为 0，检查暂存目录清理。
- 网页、Windows 网页版和桌面版、Linux 程序均已重新构建。未配置或访问真实 NAS/WebDAV 服务；协议验证使用本地模拟服务。
